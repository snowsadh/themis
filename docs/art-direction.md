# Themis courtroom art

Original courtroom and character illustrations generated with the built-in `image_gen.imagegen` tool for this project. No Ace Attorney character designs, logos or source assets were used. UI layout, folder cards, dialogue boxes and motion are implemented in CSS. Assets live in `frontend/public/art/`. Generated PNGs were encoded as lossless WebP with ImageMagick for delivery; pixel comparisons reported zero differences for all four assets.

Direction: an Indian courtroom visual novel, aubergine ink, warm teak, coral, sage and lavender; clear game choices and deliberately paced rulings. Respect reduced-motion preferences. Decorative art has empty alt text; controls and hearing text remain accessible HTML.
